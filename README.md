Autism Spectrum Disorder (ASD) is a neurodevelopmental condition marked by challenges in social communication and the presence of restricted, repetitive behaviors. We propose a comprehensive method for improving ASD classification using resting-state fMRI data from the ABIDE dataset. Our approach extracts multiple types of features, including Pearson correlation-based connectivity, tangent space embedding, and time-series features from BOLD signals.

Through dimensionality reduction, we show that combining Pearson and Tangent features explains 69.3% of the variance while maintaining good generalization and avoiding site-specific clustering. To ensure reliability, we use rigorous cross-validation with feature selection inside each fold, preventing data leakage. We also apply correlation-based feature engineering to strengthen the model.

Our method achieves an accuracy of 69.70% ± 3.78% and an AUC-ROC of 75.16% ± 3.20%. The Pearson + Tangent feature combination delivers the most stable and optimal performance (69.60% ± 2.56% accuracy), highlighting the strong synergy between these features and demonstrating clear improvements when robust validation techniques are applied.
